# Còpia estàtica de la web de Cargo

Aquesta és una primera reconstrucció sense imatges de la web 519420.
- `index.html`: portada / llistat de treballs
- `style.css`: estil responsive
- cada `.html`: pàgina de projecte
- `images/`: carpeta on pots posar les teves imatges

Per publicar-la gratis:
1. Crea un repositori públic a GitHub.
2. Puja tots aquests fitxers.
3. Ves a Settings → Pages.
4. Selecciona Deploy from a branch → `main` → `/ (root)`.
5. GitHub et donarà una adreça `*.github.io`.

Per recuperar exactament la tipografia de Cargo, hauràs d'afegir el fitxer de Monument Grotesk que tinguis llicenciat i modificar el `@font-face` a `style.css`.
